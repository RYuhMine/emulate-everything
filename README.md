# Beurer PO 80 Firmware Emulator

A Python-based emulator for the **Beurer PO 80 pulse oximeter**, designed to run its firmware in a simulated environment.

## Features

- Emulates the firmware of the Beurer PO 80 pulse oximeter.
- Emulates its all sensors and button.
- Supports English and Ukrainian languages.
- Runs locally using Python.

## Getting Started

### Requirements

- Python 3
- Unicorn Python library
- The emulator's Python script and firmware binary (`.bin`)

### Running the Emulator

1. Download or clone this repository.
2. Make sure the Python script and firmware binary are in the expected locations.
3. Run the emulator's Python script.
